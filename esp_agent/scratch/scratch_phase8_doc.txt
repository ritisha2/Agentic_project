ESP APM — PHASE 8
EVIDENCE PACK + AGENT CONTEXT — IMPLEMENTATION DESIGN
Phase-8 baseline after Phases 1–7. This phase standardizes the evidence and context package consumed by the final advisory path.
1. Phase 8 Objective
Build the Evidence Pack and Agent Context layer that combines Asset Context, runtime telemetry/history, engineering calculations, ML outputs, knowledge/cases, events and specialist findings into a traceable, authority-aware, quality-controlled package.
It is not a KB, telemetry store, or Agent. It is the normalization, validation, ranking and packaging layer between orchestration and advisory generation.

34. Definition of Done
Evidence is structured, not only prose.
Material evidence carries provenance and quality metadata.
Knowledge authority precedence is preserved.
Objective-specific evidence requirements are enforced.
Context is assembled through the Context Builder.
Raw backend data is not dumped directly into the LLM.
Conflicts and uncertainty remain visible.
Evidence Pack is versioned/frozen.
Advisory claims can be traced to evidence.
Phase 9 can consume this layer without redesign.
